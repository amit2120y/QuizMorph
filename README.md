# QuizMorph

QuizMorph is an interactive quiz platform featuring dynamic question morphing, multiple quiz modes, instant feedback, rich UI aesthetics, and custom quiz creation.

## Features
- 🎯 **Multiple Quiz Modes**: Multiple Choice, True/False, Flashcard flip, and Fill-in-the-Blanks.
- 🎨 **Modern Aesthetics**: Dynamic themes, sleek card morphing animations, smooth transitions, and particle effects.
- 🛠️ **Custom Quiz Builder**: Easily create, edit, save, export, and import custom quiz packs.
- 📊 **Progress & Analytics**: Instant scoring, detailed post-quiz breakdowns, and high score tracking.
